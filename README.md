2. Color Palette

Use a sophisticated dark color system based on these colors:

Primary:

Black / near-black: #050505

Deep black: #080808

Main Accent:

Hot Pink / Neon Pink: #FF1493 or a sophisticated hot-pink variation

Secondary Accent:

Electric Blue: #00A8FF / #2196FF

Text:

Primary text: White #FFFFFF

Secondary text: Soft white / light gray

The colors must be used carefully.

Do NOT make the website look rainbow-colored.

The visual hierarchy should mainly be:

Black → White → Hot Pink → Electric Blue

Hot pink should be the main visual identity, while blue should be used for highlights, glows, links, small UI elements, gradients and interactive states.

Use subtle pink/blue gradients only where they improve the design.

17. IMPORTANT CODE STRUCTURE

This is extremely important:

Do NOT put everything into one file.

Create a clean structure with separate files:

portfolio/
│
├── index.html
├── style.css
├── script.js
│
├── assets/
│   ├── images/
│   └── icons/
│
└── README.md


HTML

All website structure and sections must be inside:

index.html

CSS

ALL styling must be inside:

style.css

Do not put large amounts of CSS inside HTML.

JavaScript

ALL interactions, animations, mobile menu, scroll effects and other functionality must be inside:

script.js

Do not put unnecessary inline JavaScript inside HTML.

The HTML file should properly link:

<link rel="stylesheet" href="style.css">


and:

<script src="script.js"></script>


Make sure the files work together immediately when opened locally in VS Code using Live Server.

18. Code Quality

Write clean, beginner-friendly and well-organized code.

Use semantic HTML5.

Use CSS variables for the color palette, for example:

:root {
    --black: #050505;
    --dark: #080808;
    --pink: #ff1493;
    --blue: #00a8ff;
    --white: #ffffff;
}


Organize CSS into logical sections:

Variables

Reset

Global styles

Navbar

Hero

About

Services

Tech Stack

Projects

Process

CTA

Contact

Footer

Responsive styles

Keep JavaScript organized and commented.

19. Final Design Direction

The final website should look like a premium AI automation freelancer/developer portfolio, not a college assignment.

Imagine:

Black futuristic interface + hot pink identity + electric blue technical highlights + white typography + subtle glassmorphism + elegant animations.

The result should make a potential client think:

“This person understands AI, automation and modern technology — I want to see what she can build.”

Prioritize visual hierarchy, professionalism, readability, conversion and aesthetics.

Make the design memorable but not overwhelming.

Most importantly:

Do not overuse pink and blue. Use them strategically so the website remains elegant, premium and sophisticated.
